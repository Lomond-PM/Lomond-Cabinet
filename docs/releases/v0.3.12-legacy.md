# Lomond Cabinet v0.3.12 — Legacy

## Purpose

`v0.3.12 — Legacy` freezes the product immediately before the 0.3.13 / 0.3.14 UI platform rebuild and full product-page migration. It is the durable pre-rebuild baseline for comparison, rollback and historical reference.

This Legacy label does **not** mean Vela has completed model qualification, complete AE capability coverage, or a separate long-term maintenance commitment.

Publication is represented by the immutable GitHub `v0.3.12` tag / Release. This file intentionally describes the durable release identity rather than a transient published/unpublished state, so the same text remains valid before and after publication when the prepared contents are unchanged.

## Highlights

### Vela safety and execution facts

- Preserves the bounded Agent loop, streaming text/reasoning presentation, multi-conversation foundation, and supported opacity / rename / ordered two-step path.
- Review now exposes complete local before/proposed values, reliable target identity and current-step approval scope.
- Final Verify is associated with the actual committed target; no-op / already-satisfied work performs no unnecessary mutation while still requiring fresh Verify.
- Session, Driver and trajectory facts distinguish committed `true` / `false` / `null` instead of inferring success from UI state.
- Background-task stop, Provider disable/acknowledgement withdrawal and readiness invalidation preserve the correct active owner and do not revive old grants, reviews or objectives.
- Streaming terminal handling is monotonic and fails closed on contradictory or post-terminal content.

### Host and ordinary-tool safety

- Hardened public Host JSON parsing/serialization and Unicode / UTF-8 parameter validation.
- Tightened Ad Component Kit / Text Background Box geometry and coordinate-space behavior within the accepted 2D support envelope.
- Preserved source comments and tool-owned expression restoration rules across Detach / Remove paths; Remove validates restoration evidence before destructive cleanup and reports partial failure rather than inventing rollback.

### User assets and UI exit safety

- Palette / Appearance persistence separates `accepted`, `applied` and `persisted` facts.
- Failed reads or saves do not delete unknown previous assets or silently replace them with defaults.
- External snapshots no longer leak mutable nested references from Appearance / Design Tuning state.
- Escape is consumed by the intended interaction layer; dirty Palette exits negotiate save / discard / continue-editing before route change or disposal.

## Validation baseline

0.3.12-G sealed on the final implementation state with:

- **198 / 198** offline suites PASS
- **0 FAIL / 0 skip**
- real AE / CEP single-step Review → mutation → original-target Verify → native Undo evidence
- real supported two-step objective with first-step write + Verify, independent second Review, second-step Reject, and preserved partial-completion facts
- real Grid / Feature Create→Remove recovery and native Undo representatives
- controlled CEP production-composition evidence for storage faults, lifecycle windows and in-flight settlement where natural fault injection was unsafe

Primary real acceptance environment was After Effects 26.0x67 / AdobeCEP 12.0.1 / Chrome 99 / Windows Win64. Historical environment-specific and controlled-evidence boundaries remain documented in the 0.3.12 reports.

## Vela support boundary

Vela remains an **Experimental Preview** and is disabled by default. Readiness only confirms that the configured local Provider/model instance is reachable and loaded; it is not model qualification. No qualified default model is declared by this release.

The existing 120000 ms whole-request Provider deadline remains. Historical `PROVIDER_TIMEOUT` failures are preserved with unknown root cause/token counts; one successful representative does not prove the latency risk has disappeared. Provider/context observability is scheduled for 0.3.16 and formal configuration-level model qualification for 0.3.25.

## UI generation boundary

This release retains the pre-rebuild production UI. The accepted UI Lab visual direction belongs to the 0.3.13 platform-rebuild work and is **not** retroactively part of the Legacy UI.

Liquid Glass remains an isolated UI Lab material experiment. Its optical rendering, anti-aliasing, capability gate and graceful fallback are exploratory and do not block the non-glass UI platform rebuild.

## Remaining documented limitations

Examples that remain explicitly bounded include natural Host/Verify in-flight UI timing windows, special Host environments, AE26.3 cross-version revalidation for some Host geometry paths, AV fallback real-AE coverage, retained Detach UI/registration scope, IME/DPI/long-run coverage, complete source audit coverage, complete AE Action coverage and model qualification.
